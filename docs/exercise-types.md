
# Exercise Types

## Active recall

Research consistently shows that **being tested** on material is
more effective than simply re-reading it. This is the **testing
effect** (also called active recall): the act of retrieving an
answer from memory strengthens the memory itself.

Rembrandt uses two exercise types that leverage active recall at
different difficulty levels.


## Flashcard

> "Translate this word: **cat**"

You see the source word and must produce the translation entirely
from memory. There are no hints or options — you either know it or
you don't. This is **pure recall** and is the harder of the two
exercise types.

Generated by `generate_flashcard()` in
`src/rembrandt/exercises.py`.


## Multiple choice

> "Translate this word: **cat**"
> a) perro  b) gato  c) casa  d) libro

You see the source word and a set of options (default: 4). One is
the correct translation; the rest are distractors drawn randomly
from other words in the same language pair. This is **recognition**
rather than recall — easier, because seeing the right answer can
jog your memory.

Generated by `generate_multiple_choice()` in
`src/rembrandt/exercises.py`. The correct answer is shuffled into
a random position among the distractors.


## Reverse flashcard

> "Definition: lasting for a very short time"
> "Which word matches? ___"

You see the definition (or translation) and must type the **word**
itself. This is the reverse of a regular flashcard — instead of
producing the meaning, you produce the term. Particularly useful
in definition mode, where typing an entire definition would be
impractical.

Generated by `generate_reverse_flashcard()` in
`src/rembrandt/exercises.py`.


## Self-graded

> "Word: **ephemeral**"
> *(Think of the definition...)*
> "Reveal: lasting for a very short time"
> "How well did you know it? (0-5)"

You see the word, mentally recall its meaning, then reveal the
answer and rate yourself on a 0-5 scale. This mirrors physical
flashcard behaviour and feeds the quality score directly into
the SM-2 algorithm for fine-grained scheduling.

Generated by `generate_self_graded()` in
`src/rembrandt/exercises.py`.


## Learning modes

Rembrandt supports two learning modes, determined automatically
by the language pair:

### Translation mode

When `language_from != language_to` (e.g. EN -> ES), you are
learning translations between two languages. This is the
traditional vocabulary study mode.

### Definition mode

When `language_from == language_to` (e.g. EN -> EN), you are
learning words through their definitions within the same
language. Useful for enriching vocabulary in your own language
or learning advanced/academic terms.

No model or database changes are needed — simply add words where
both languages are the same:

```python
from rembrandt import Word

db.add_words([
    Word(language_from="en", language_to="en",
         word_from="ephemeral",
         word_to="lasting for a very short time"),
])
session = Session(db, "user1", "en", "en")
```


## Gender/article match

> "___ libro"
> a) el  b) la

You see a Spanish noun with a blank where the article should be
and select the correct definite article (`el` for masculine,
`la` for feminine). This tests grammatical gender knowledge —
a skill that has no direct equivalent in English and requires
dedicated practice.

Only available for words that have `gender` set (`"m"` or `"f"`).

Generated by `generate_gender_match()` in
`src/rembrandt/exercises.py`.


## Verb conjugation

> "hablar — presente, yo"
> "___"

You see a Spanish verb infinitive with a tense and person label,
and must type the correct conjugated form. This tests verb
morphology — regular -ar/-er/-ir endings and common irregular
verbs across three tenses (presente, pretérito, imperfecto).

Only available for verbs that have `conjugation_group` set and
can be conjugated by the built-in engine (15 irregular verbs +
all regular verbs).

Generated by `generate_conjugation()` in
`src/rembrandt/exercises.py`. Conjugation logic lives in
`src/rembrandt/conjugation.py`.


## How Rembrandt picks the exercise type

The `generate_exercise()` function chooses exercise types based
on the learning mode:

**Translation mode** — pool-based random selection:

- Base pool: **flashcard** + **multiple choice** (equal weight).
- If the word has `gender` set: **gender match** is added.
- If the word has `conjugation_group` and is conjugable:
  **conjugation** is added.
- If there are **fewer than 2 words** in the pool, multiple
  choice isn't possible, so it falls back to **flashcard**.

**Definition mode** — 40% multiple choice, 30% reverse
flashcard, 30% self-graded:

- Regular flashcard is **never** used (typing exact definitions
  is bad UX).
- If there are **fewer than 2 words** in the pool, it falls
  back to **reverse flashcard**.

This keeps sessions varied without requiring any configuration.


## Answer evaluation

When you submit an answer, `evaluate_answer()` compares it against
the expected value:

- **Case-insensitive**: "Gato" and "gato" are both correct.
- **Whitespace-stripped**: " gato " and "gato" are both correct.
- **Reverse flashcard**: the expected answer is `word_from` (the
  term) instead of `word_to`.
- **Self-graded**: no text comparison — correctness is determined
  by the quality score (`correct` when quality >= 3).
- **Accent-tolerant**: "hablo" matches "habló" (diacritics
  are stripped before comparison).
- For exercises with an explicit `expected_answer` (gender match,
  conjugation, cloze), that value is used directly.

The result is an `AnswerResult` that tells you whether you were
correct, what the expected answer was, and what you actually typed.

After evaluation, the [spaced-repetition algorithm](spaced-repetition.md)
updates your progress: correct answers push the next review further
out, wrong answers bring the word back sooner.
